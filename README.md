# 📚 Biblioteca de Livros em Python

## 📝 Sobre o projeto

Este projeto consiste em um sistema simples de biblioteca desenvolvido em Python, utilizando o terminal para permitir o cadastro e a visualização de livros.

O objetivo é praticar conceitos fundamentais da programação, como listas, dicionários, funções, estruturas condicionais, laços de repetição e entrada de dados do usuário.

## ⚙️ Funcionalidades

- **Adicionar livros:** permite cadastrar o nome de um livro e seu respectivo autor.
- **Listar livros:** exibe os livros cadastrados, seus autores e uma quantidade gerada aleatoriamente.
- **Menu interativo:** apresenta opções para navegar pelo sistema.
- **Sair do programa:** encerra a execução da biblioteca.
- **Limpar a tela:** organiza a interface do terminal durante a navegação.

## 🛠️ Tecnologias utilizadas

- Python 3
- Módulo `os`
- Módulo `random`

## ▶️ Como executar o projeto

1. Instale o [Python](https://www.python.org/downloads/), caso ainda não tenha instalado.
2. Clone este repositório ou baixe os arquivos do projeto.
3. Abra o terminal na pasta do projeto.
4. Execute o comando:

```bash
python main.py
```

## 📖 Conceitos praticados

Durante o desenvolvimento, foram utilizados:

- Listas para armazenar os livros cadastrados.
- Dicionários para organizar as informações de cada livro.
- Funções para estruturar partes do programa.
- Estruturas condicionais (`if`, `elif` e `else`).
- Laço de repetição `while` para manter o menu em execução.
- Laço `for` e `enumerate()` para percorrer e numerar os livros.
- Entrada de dados com `input()` e exibição de informações com `print()`.
